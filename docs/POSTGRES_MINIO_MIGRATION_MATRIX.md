## Purpose

The repository now contains gated migration, artifact, readiness, and backup tooling, but this is not evidence that PostgreSQL, MinIO, release control, or durable job events are active in the current deployment.

## Required schema invariants

Every tenant-owned table must contain a non-null `tenant_id` foreign key after the backfill gate. Every tenant-scoped lookup, uniqueness constraint, idempotency key, and deletion policy must include that tenant boundary. Ownerless legacy rows must be represented in a quarantine set or migration exception report and must never be silently assigned to a tenant.

Artifact manifests must contain `tenant_id`, object key, checksum, byte size, media type, source relation, creation time, and lifecycle status. Application responses should expose signed URLs or opaque artifact identifiers rather than local filesystem paths. Object keys must be generated by the server and must not be accepted as arbitrary filesystem paths.

| 6 | MinIO artifact manifest and object migration | Checksums, signed access, owner checks, lifecycle cleanup, restore test |
| 7 | Queue/job authority migration | Transactional job ownership, idempotency, retries, dead letters, durable events |
| 8 | Controlled primary-read change | Only after acceptance, rollback rehearsal, and owner approval; keep `RELEASE_CONTROL_PRIMARY_READS=false` until then |

## Explicit non-goals and safeguards

This matrix does not fabricate provider credentials, OAuth tokens, tenant ownership, or missing archived features. PostgreSQL and MinIO must be introduced as separately tested capabilities. The current Docker stack contains the application and Redis; it does not prove that PostgreSQL, MinIO, release control, or durable job events are present.

The first implementation slice should cover tenant/profile/account metadata, schedules, quotas, publishing/render job metadata, and artifact manifests. Credential values should be migrated only through a managed secret mechanism, and no secret should be copied into PostgreSQL plaintext, application logs, or exported JSON.
