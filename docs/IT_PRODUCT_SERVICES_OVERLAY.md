# IT Product & Services Showcase Overlay

The platform now has a fifth primary overlay for IT products and services. It is selected by the `ITServices` canonical profile and aliases including `IT`, `IT services`, `IT products`, `IT product services`, `software services`, `SaaS marketing`, and `technology services`.

The overlay is intended for software products, SaaS, websites, automation, AI tools, cloud and hosting, DevOps, cybersecurity, ERP/CRM, IT support, maintenance, and custom development. Its composition presents a service label, outcome-led headline, capability chip, scene progress, and a practical next-step line. It does not create testimonials, ratings, customer names, performance metrics, integrations, scores, or guarantees that are not present in the source metadata.

Routing is exclusive: News uses `NewsOverlay`, general Marketing/Business uses `MarketingOverlay`, Sports uses `SportsOverlay`, knowledge-oriented categories use `AdvancedKnowledgeOverlay`, and IT products/services use `ITProductShowcaseOverlay`.

The local validation gate passed TypeScript and the focused profile/template suite: 15 tests passed. A representative IT MP4 render remains the next runtime validation step before automatic release use.
